# Cursed Spawners — Unofficial Forge 1.20.1 Backport

This repository contains an **unofficial modified backport** of [Cursed Spawners](https://github.com/Provismet/Cursed-Spawners) by Provismet, based on the original `1.0.0-mc1.21` release.

## Target

- Minecraft 1.20.1
- Forge 47.x
- Java 17
- Intended for Forge modpacks such as All the Mods 9

The Forge loader mod id is `cursed_spawners` because Forge 1.20.1 loader ids cannot contain hyphens. The original `cursed-spawners` resource/registry namespace is retained where possible for compatibility with original assets and identifiers.

## Status

The Forge 1.20.1 backport builds successfully against Forge 47.4.16 and has passed automated dedicated-server and headless-client startup smoke tests. The next validation layer is gameplay testing inside a real modpack such as ATM9.

Do not report issues with this unofficial backport to the original Cursed Spawners author.
